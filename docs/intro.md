# Welcome to AdamaJava

The project is being hosted on
[github](https://github.com/AdamaJava/adamajava).

While the repository contains code for dozens of utilities, the list below
shows tools that are considered robust enough to be released for general use.
Most are written in Java and require version 21. Some tools have dependencies
on other software.

* [qannotate](qannotate/index.md) - adds annotations to a VCF file, or creates an annotated TSV file from a VCF file
* [qbamfilter](qbamfilter/index.md) - filters records from a BAM file
* [qbasepileup](qbasepileup/index.md) - base pileups
* [qcnv](qcnv/index.md) - a pre-processor for copy number variant (CNV) calling
* [qcoverage](qcoverage/index.md) - calculates read depth statistics for a mapped BAM
* [qmito](qmito/index.md) - metrics for mitochondrial sequencing
* [qmotif](qmotif/index.md) - search BAM file records for base motifs
* [qmule](qmule/index.md) - collection of helper modes for NGS
* [qpileup](qpileup/index.md) - gathers base-level metrics across a whole genome from a group of BAMs
* [qprofiler](qprofiler/index.md) - QC assessment of BAM files using summary statistics
* [qprofiler2](qprofiler2/index.md) - summary metrics for BAM, FASTQ and VCF files
* [qsignature](qsignature/index.md) - sample mixup detection
* [qsnp](qsnp/index.md) - heuristics-based tumour/normal single nucleotide variant (SNV) caller
* [qsv](qsv/index.md) - tumour/normal structural variant (SV) caller
* [qvisualise](qvisualise/index.md) - creates HTML reports from qprofiler XML reports
